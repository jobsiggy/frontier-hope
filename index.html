GETTING STARTED
Help & how to use
A practical guide to adding public evidence, reading the map, and preparing a prompt for Arena AI Agent Mode.

          

            
Quick start

              
01
Add a public source
Open . Fetch a public RSS / Atom URL, paste a feed export, or manually add a public post with its original link and publication date. If a publisher blocks browser CORS, use a local export instead.

              
02
Check the evidence
Use the signal inbox to search by lab, source type, or topic. Open the original source to confirm context. Pin only the real imported records you want attached to your Arena prompt.

              
03
Read the map carefully
The frontier map groups titles and snippets with simple keyword rules. Coverage means record count and source mix—not confidence, internal knowledge, or a forecast.

              
04
Build and use an Arena prompt
Open Prompt Studio, edit the 10-step brief, review the live evidence inventory, then copy it. Open Arena AI Agent Mode and paste the prompt into a new chat. Nothing is sent automatically.

              
05
Evaluate the result
Generate a rubric and eval spec, or prepare a best-of-N pack for separate chats. The pack only duplicates the prompt; you run and compare each result in Arena yourself.

            

            
Adding RSS, Atom, and social signals
Direct feed fetching uses the browser's normal fetch() request. Many feed hosts do not allow cross-origin browser reads, so a CORS error is expected for some publishers; this app deliberately does not route data through an untrusted proxy. Download the public feed and import the XML / JSON / CSV file, or paste its contents.
Social posts are manual by design. Paste only content you can publicly access, keep its source URL, and avoid collecting personal information unrelated to the research question. No cookies, credentials, login-only pages, private APIs, or automated social scraping are used.

            
How the “collective roadmap” is formed
Signals are assigned to a small topic taxonomy using visible keyword rules (agents and tools, model efficiency, multimodal, infrastructure, safety and alignment, robotics, and data and training). The counts help you find recurring public themes; they do not prove that a lab has an active project or a planned product.
Before making a claim, verify the date and original source, compare independent evidence, distinguish observation from inference, and note uncertainty. Job listings and social posts are clues, not confirmed roadmaps.

            
Export, reset, and portability
Prompt Studio can export the Prompt Brief as Markdown and the wizard answers plus imported records as JSON. Wizard and intake state are saved in your browser's local storage, so the data will not sync to another device. Use the export before clearing browser data or moving workspaces.
“Clear imported data” removes saved user records and feed URLs from this browser. It does not delete source material from its publisher. Demo examples are part of the static app and can be hidden with the demo toggle.

          
Privacy & limits
●All feeds, pasted posts, and prompt drafts are processed in this browser.
●Saved data uses localStorage. Avoid storing sensitive or private material.
●No AI inference, live social API, server, telemetry, auth, or background crawl is included.
●Seed records are fictional demos. They are excluded from generated evidence inventories.
●Topic grouping is a transparent keyword heuristic, not a model or a guarantee.
Recommended checks
  • Open the source URL and confirm the quote, author, and date.
  • Keep at least one direct source link for every factual claim.
  • Do not infer private plans from public signals.
  • Use the quality checker as a checklist, not a score guarantee.
  • Verify all generated files and outputs before saying a task is done.
Deployment
This is a self-contained static app. Serve index.html from Cloudflare Pages or GitHub Pages; no build command is required. See the repository README for steps and known limits.
